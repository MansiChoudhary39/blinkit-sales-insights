# 📊 Blinkit Sales Analysis – Excel Dashboard

## 📌 Project Overview

This project is an end-to-end **Blinkit Sales Analysis Dashboard** developed using Microsoft Excel.

The project focuses on analyzing sales performance, product categories, outlet characteristics and customer ratings through an interactive Excel dashboard.

The complete analysis is maintained in a single connected Excel workbook, including data, calculations, Pivot Tables, charts and dashboard components.

---

## 🎯 Project Objective

The objective of this project is to transform raw Blinkit data into meaningful business insights and provide an interactive dashboard for analyzing sales and outlet performance.

## 📈 Dashboard Analysis

The dashboard provides analysis across multiple business dimensions:

- **Outlet Establishment** – Sales performance based on outlet establishment year
- **Fat Content** – Sales comparison between Low Fat and Regular products
- **Item Type** – Sales performance across different product categories
- **Outlet Size** – Performance comparison of High, Medium and Small outlets
- **Outlet Location** – Sales comparison across Tier 1, Tier 2 and Tier 3 locations
- **Outlet Type** – Comparison of Total Sales, Average Sales and Number of Items

---

## 🔍 Interactive Dashboard

The dashboard includes filters for:

- Outlet Size
- Outlet Location
- Item Type

These filters allow users to interact with the dashboard and analyze specific segments of the business.

---

## 💡 Key Insights

- Blinkit generated approximately **$1.20M** in total sales across the analyzed data.
- The average sales value is approximately **$141**.
- The dataset contains **8,523 items**.
- The overall average customer rating is **4.0**.
- **Regular-fat products** contribute a larger share of sales compared with Low Fat products.
- **Fruits & Vegetables** and **Snack Foods** are among the highest-selling item categories.
- **Tier 3 outlets** show the highest sales contribution among the three outlet locations.
- Sales performance varies across different outlet types and outlet sizes.
